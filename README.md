# HSRW Submarine Team 🌊

The official website for the **HSRW Submarine Team** — a student engineering group at Hochschule Rhein-Waal (Kleve, Germany) designing and building a human-powered submarine.

**Live site:** [[serene-babka-6a57a2.netlify.app](https://serene-babka-6a57a2.netlify.app)](https://hsrwsubmarine.netlify.app/)


---

## About the Team

A previous generation of HSRW students designed and built a working human-powered submarine — a serious engineering achievement. After that team graduated, the project went quiet for several years.

We're a new team restarting the mission: rebuilding the group, refreshing the engineering, and preparing to get back in the water.

**Core focus areas:**
- Human-powered propulsion
- Hull design & hydrodynamics
- Mechatronic systems (controls, sensors, drivetrain)

## Tech

This site is a single self-contained `index.html` file — no build step, no dependencies. All images are embedded as base64 so it can be dropped anywhere and just works.

- Plain HTML/CSS/JS
- Fonts: Barlow Condensed + Inter (Google Fonts)
- Scroll-triggered animations via `IntersectionObserver`
- Deployed on [Netlify](https://netlify.com)

## Deploying Changes

1. Edit `index.html` (locally or directly in GitHub).
2. Commit to `main`.
3. Netlify auto-redeploys within a minute or two.
